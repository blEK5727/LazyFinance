# Lazy Finance landing page

A responsive concept landing page for Lazy Finance, built with plain HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` directly in a browser, or run a local server from this folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Files

- `index.html` contains the page structure and copy.
- `styles.css` contains the responsive visual design.
- `script.js` handles reveal animations, the waitlist demo, and the approval interaction.

The waitlist form is a front-end prototype and does not send or store email addresses. Connect the form to your preferred form or email service before launch.
